### 2.1 Bootstrap trust and bounded failure

Private HTTP is the ratified bootstrap, not authenticated encryption. No claim that nonce existence authenticates the private sender: A1 nonce rows do not store the signed metadata fingerprint. The private boundary trusts the admitted API host/network, not arbitrary clients presenting copied UUIDs. No mTLS prerequisite is added.

Mandatory endpoint checks: listen on the configured private/loopback IP only; compare the socket remote address against an explicit API-peer IP allowlist; do not trust Forwarded/X-Forwarded-For; require exact configured Host/port; no proxy/redirect route, open listener wildcard, public binding or automatic discovery. A shared trusted host/IP is one trust domain, not process cryptographic isolation. In synthetic qualification, attempt direct calls from an untrusted peer and a spoofed forwarded address: both must fail before B. The existing production hard stop remains; passing synthetic network tests is not a production security certification.

Private malformed/network admission fails with an empty HTTP 400/403; dependency/transaction exceptions produce empty 503. API maps private protocol/availability failures to existing NOT_READY, preserves N and never reads/drains the raw request. Valid business `Final` and `Handoff` are HTTP 200. No database exception, SQL token or reference is exposed in an error body.

### 3.3 NPS01 — committed R1 with no provider start
