# TagEkyc Process Improvements

This folder stores candidate process improvements that have not yet been
ratified into `docs/00_REVIEW_AND_TIP_PLAYBOOK.md`.

## Lifecycle

- `IDEA`: recorded but not yet trial-ready.
- `CANDIDATE`: specified and eligible for a bounded pilot.
- `ACTIVE`: binding only to the explicitly named pilot.
- `COMPLETED`: pilot evidence is complete and awaits a decision.
- `RATIFIED`: promoted into the canonical playbook.
- `REVISE_AND_RETRIAL`: requires another explicitly authorized pilot.
- `REJECTED`: not adopted.
- `SUPERSEDED`: replaced by a named artifact.

Candidate files are not generally binding. A root instruction or explicit
Homeowner direction may activate one for a bounded pilot.
